# Lady-Bug-
A set of recipies done in Ladybug Plugin of Rhino 

This repository contains a comprehensive suite of Grasshopper workflows using Ladybug Tools, designed to integrate data-driven environmental analysis directly into the architectural design process. The collection includes parametric recipes for foundational climate data parsing, solar radiation and massing studies, outdoor microclimate and thermal comfort evaluation, as well as daylight, glare, and visual performance metrics. By bridging the gap between local weather data and complex building geometry, these scripts empower designers to optimize building forms, develop targeted shading strategies, and enhance overall occupant comfort.
